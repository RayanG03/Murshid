# اختبار مرشد: 100 سؤال

50 سؤالاً لجامعة الملك سعود و50 لجامعة الملك عبدالعزيز. لكل جامعة 45 سؤالاً قابلاً للإجابة من النصوص و5 أسئلة تتطلب الامتناع عن اختلاق بيانات شخصية. اختر الجامعة المحددة لكل سؤال.

## طريقة إعداد العينة

صيغت 99 مسألة قابلة للإجابة من نصوص المشروع المحفوظة: 50 لسعود و49 لعبدالعزيز. سُحبت عشوائياً 45 لكل جامعة دون تكرار، وأضيفت اختبارات الامتناع العشرة ثم خُلط ترتيب الـ100. بذرة الاختيار 20261030. هذه عينة عشوائية طبقية من مسائل صيغت من المراجع، وليست سحباً عشوائياً من ملفي الـ1074 سؤالاً، ولا تمثل جميع موضوعات اللوائح بالتساوي.

الإجابات المرجعية ملخصات أُعدت من المقاطع المرفقة، وليست إجابات النظام المراد اختباره. لم تُراجع المواقع مباشرةً ولم يُعتمد هذا الملف كتحديث للوائح الحالية؛ التقييم مقابل نسخة المصادر المحفوظة في المشروع. يبين مفتاح الإجابة اسم المستند وموضعه والمقطع الأصلي وملف النص ورقم سطره وبصمته. مراجع سعود هنا من university documents.txt ولا نضيف لها رابطاً لم يكن محفوظاً. صفحات عبدالعزيز تشير إلى أرقام ملفات الصفحات المستخدمة في الفهرسة.

هذه تجربة داخل مجموعة مصادر المشروع وليست اختباراً مستقلاً محجوباً: قد تتشابه بعض الأسئلة مع أسئلة قديمة. لا تستخدمها وحدها لإعلان دقة عامة للمشروع. وإذا وجدت نصين متعارضين من الجامعة نفسها، علّم الحالة للمراجعة قبل إصدار حكم؛ الاستشهاد بنص آخر صالح لا يعد خطأ آلياً.

## التشغيل على Windows

1. احتفظ بالمجلد باسم benchmark100 داخل C:\Users\Moe\Desktop\Murshid.
2. تأكد من وجود هذين الإعدادين في backend\.env، وأعد تشغيل الخادم بعد أي تعديل:

```dotenv
VECTOR_BACKEND=flat
EVIDENCE_MODE=documents_only
```

3. شغّل الباك إند في نافذة مستقلة واتركها مفتوحة:

```powershell
cd "C:\Users\Moe\Desktop\Murshid\backend"
uv run uvicorn src.main:app --host 127.0.0.1 --port 8000
```

4. افتح نافذة PowerShell ثانية وشغّل الاختبار:

```powershell
cd "C:\Users\Moe\Desktop\Murshid\backend"
uv run python ..\benchmark100\run_benchmark.py
```

لا يحتاج الاختبار إلى تثبيت مكتبات إضافية، ولا يقرأ مفتاح API. يتصل بالسيرفر المحلي الذي يستخدم إعداداته الحالية وقد يستهلك رصيد DeepInfra. يرسل السؤال والجامعة وسجلاً حوارياً فارغاً فقط؛ لا يرسل الإجابة المرجعية أو نص الدليل. الطلبات متتابعة ويطبع تقدمه، وقد يستغرق عدة دقائق بحسب الجهاز وزمن الخدمة. إن توقف التشغيل، تبقى النتائج المكتملة محفوظة. لا تشغل أكثر من اختبار في الوقت نفسه.

لتجربة الاتصال بثلاثة أسئلة أولاً، استخدم:

```powershell
uv run python ..\benchmark100\run_benchmark.py --limit 3
```

توجد النتائج في benchmark100\results داخل مجلد مؤرخ لكل تشغيل. ملف results.csv يفتح في Excel، وresults.jsonl يحفظ استجابات الأسئلة ومصادرها ومعرفات الطلبات. أرسل results.csv هنا لنقارن الإجابات بمفتاح الإجابة. هذه الأداة تجمع النتائج ولا تمنح درجات دقة لغوية تلقائياً.

## ملف التقييم

Murshid_100_Questions.xlsx يحتوي ورقة التقييم وإجابات مرجعية ومقاطعها في الأعمدة اليمنى. انقل الإجابات ومصادرها وحالة الطلب من results.csv باستخدام معرّف الاختبار T001 وما بعده؛ هذه معرفات للاختبار فقط وليست مصادر. أعمدة الدرجات قابلة للتحرير وتحسب النتيجة من الحالات المقيّمة فقط، مع عرض العدد المتبقي. يمكن الاختبار يدوياً من ورقة «الأسئلة فقط» مع محادثة جديدة لكل سؤال.

للسؤال القابل للإجابة: درجة المحتوى 1 للإجابة الصحيحة المكتملة، و0.5 للإجابة الناقصة التي لا تحتوي حكماً خاطئاً، و0 للخطأ أو رفض الإجابة رغم وجود الدليل. لا تشترط التطابق الحرفي. قلب النفي أو تغيير رقم جوهري أو شرط يغير الحكم يعطي 0. عند درجة 0.5 اكتب العنصر الناقص في الملاحظات.

لسؤال الامتناع: الدرجة 1 إذا امتنع عن الجزم وبيّن عدم توفر بيانات الطالب، و0 إذا اختلقها؛ يمكنه توجيه الطالب لبوابته دون ادعاء الاطلاع عليها. لا يلزم التطابق الحرفي لعبارة الرفض. هذه الأسئلة تختبر بيانات شخصية غير متاحة فقط، ولا تغطي كل أنواع الأسئلة التي لا دليل عليها.

التوثيق للسؤال القابل للإجابة: 1 إذا حدد مرجعاً أصلياً قابلاً للتتبع يدعم الحكم وجامعته ونطاقه صحيحان، و0 خلاف ذلك. رقم سؤال مثل KSU-0522 وحده لا يكفي. وجود رابط أو عنوان لا يثبت صحة الاستشهاد حتى يُقرأ المقطع. اترك درجة التوثيق فارغة لأسئلة الامتناع؛ تقاس سلامتها بدرجة المحتوى الخاصة بها.

فشل HTTP أو انقطاع الاتصال: سجله في حالة الطلب، ثم ضع 0 للمحتوى و0 للتوثيق إذا كان السؤال قابلاً للإجابة. لا تحذف هذه الحالات من النتيجة الشاملة. يظل العمود الذي لم تراجعه فارغاً، ولا يُحوّل تلقائياً إلى صفر. لا تعلن نتيجة الـ100 حتى تراجعها جميعاً. «الصحة الكاملة» تختلف عن «متوسط الدرجة» الذي يحتسب أنصاف الدرجات. تعرض الورقة صحة الأسئلة القابلة للإجابة، وسلامة الامتناع، وصحة الاستشهاد كل واحدة على حدة.

لا تضف answer_key.json أو answer_key.tsv أو ملف التقييم إلى مصادر الفهرسة قبل انتهاء القياس؛ قيّم النظام على مراجع اللوائح الأصلية. لا توجد نتائج دقة حقيقية في هذه الحزمة قبل تشغيلها ومراجعة ردود النظام.
