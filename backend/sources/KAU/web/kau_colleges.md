# كليات جامعة الملك عبدالعزيز

## عدد الكليات
بحسب الصفحة الرسمية للجامعة يبلغ عدد الكليات والمعاهد 33 كلية ومعهداً (رقم يجمع الكليات والمعاهد معاً).
ويذكر دليل القبول لبرامج البكالوريوس والدبلوم 21 كلية بالاسم تطرح برامج للطلبة المستجدين.

## الكليات الصحية
كلية الطب، كلية علوم التأهيل الطبي، كلية التمريض، كلية طب الأسنان، كلية الصيدلة، كلية العلوم الطبية التطبيقية.

## الكليات الهندسية والعلمية
كلية الهندسة، كلية الحاسبات وتقنية المعلومات، كلية العمارة والتخطيط، كلية التعدين، كلية العلوم، كلية الدراسات البحرية بأبحر، كلية علوم البحار، كلية العلوم البيئية.

## الكليات الإنسانية والإدارية والتطبيقية
كلية علوم الإنسان والتصاميم، كلية السياحة، كلية الاتصال والإعلام، كلية الحقوق، كلية الآداب والعلوم الإنسانية، كلية الاقتصاد والإدارة، الكلية التطبيقية.

## تخصصات كلية الحاسبات وتقنية المعلومات
علوم الحاسبات، تقنية المعلومات، نظم المعلومات، الأمن السيبراني.
