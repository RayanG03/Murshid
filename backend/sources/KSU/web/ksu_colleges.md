# كليات جامعة الملك سعود

## مجموعات الكليات
تقسم الجامعة كلياتها رسمياً إلى: الكليات العلمية، والكليات الصحية، والكليات الإنسانية، وكلية الدراسات التطبيقية وخدمة المجتمع، وكليات فرع المزاحمية، إضافة إلى السنة الأولى المشتركة.
لا تذكر المصادر المتاحة عدداً رسمياً إجمالياً للكليات.

## أمثلة على كليات الجامعة وسنة إنشائها
كلية الآداب (1957م، أول كلية)، كلية العلوم وكلية إدارة الأعمال وكلية الصيدلة (1958-1960م)، كلية الزراعة وكلية الهندسة وكلية التربية (نحو 1966م)، كلية الطب (1969م)، كلية طب الأسنان وكلية العلوم الطبية التطبيقية (1976م)، كلية علوم الحاسب والمعلومات وكلية العمارة والتخطيط (1983م)، كلية اللغات والترجمة (1994م)، كلية الدراسات التطبيقية وخدمة المجتمع (2000م)، كلية التمريض (2003م).
وتذكر الجامعة في تقريرها السنوي 2024م أيضاً: كلية الحقوق والعلوم السياسية، وكلية علوم الأغذية والزراعة، وكلية العلوم الإنسانية والاجتماعية، وكلية اللغات وعلومها.
